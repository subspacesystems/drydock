# Security

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: on the repository's **Security** tab, choose
**Report a vulnerability**. Include what you found, how to reproduce it, and which version or
commit is affected.

You'll get a reply when the report has been read. Fixes go out in a regular release, and the
advisory is published once a fixed version is available. Response times vary; Drydock is
maintained by a small team.

Security fixes are made for the latest release only.
