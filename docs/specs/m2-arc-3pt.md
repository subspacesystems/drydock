# m2-arc-3pt: three-point arc tool

Module `modeler-kernel/src/tools/arc3.rs` (skeleton on main). Change only that file (add private fields and helpers; keep public signatures). No new dependencies. Never panic. Same conventions as `ArcTool` (`m2-tool-shapes`): the app passes in inferred points; "nothing changes" means model, undo stack and tool state are as before the call; a non-finite `Move` is ignored (`Ok`); a non-finite `Click` is `Err(Geometry(StickyError::NotFinite))`; `Move` while idle is ignored; `Cancel` goes idle (`Ok`). `DrawPlane` as in `m2-tool-shapes`: the shape lives in the plane through the first clicked point, later points are measured in it (the part along the normal is dropped). `TOL` = `geom::LINEAR_TOL`. The shape is drawn with one `draw_segments` call, one undo step labelled `"Arc"`. If it fails, return its error; the tool stays as before the call.

Segment count: `Typed` text ending in `s`/`S` with a whole number 1 to 360 before it sets the count in any state (`Ok`, nothing else happens); anything else of that form is `Err(Parse(Invalid))`, count unchanged. Use `circle::segment_count(text, 1)`. Default 12. It survives finishing and `Cancel`.

## `three_point_arc(normal, a, b, through, segments) -> Option<Vec<DVec3>>`
Pure. Work in the plane through `a` with the given normal (project `b` and `through` into it). The arc is the part of the circle through `a`, `b` and `through` that starts at `a`, ends at `b` and contains `through`. Returns `segments + 1` points, evenly spaced in angle along it; the first is exactly `a`, the last exactly `b` (replace the computed ends). The sweep may be above or below half a turn, clockwise or counter-clockwise: whichever side `through` is on decides. `None` when `segments == 0`, any input is non-finite or the normal has zero length, projected `a` and `b` are within `TOL`, projected `through` is within `TOL` of the line `ab`, or `through` is within `TOL` of `a` or `b`.

## `Arc3Tool`
Stages: idle; *start placed* (`a`); *end placed* (`a`, `b`).
- `placed()`: 0, 1, 2. `anchor()`: `a` in stage 1, `b` in stage 2, else `None`. `set_plane` only while idle.
- `chord()`: stage 1 with a cursor: distance from `a` to the cursor in the plane (`None` if at most `TOL`... return it only when above `TOL`); stage 2: `|b - a|`; else `None`.
- `preview()`: stage 1 with a cursor above `TOL` away: `[a, a + radial]`. Stage 2 with a cursor: `three_point_arc(normal, a, b, cursor, segments)`. Else `None`.
- `radius()`: the radius of the circle of the arc in `preview()` in stage 2 (`None` when `preview()` is `None` or in other stages).
- **Click(p)**: idle: `a = p`, no cursor. Stage 1: the in-plane vector from `a` to `p` is at most `TOL`: `Ok`, nothing changes; else `b = a + that`, no cursor. Stage 2: `three_point_arc(normal, a, b, p, segments)`; `None`: `Ok`, nothing changes; else draw its points as consecutive edges `pts[i] → pts[i+1]`; go idle, no cursor.
- **Typed(text)** (not a segment count): idle: `Err(NotStarted)`. Stage 1: a length via `parse_length(text, target.unit)` (error `Err(Parse(e))`), absolute value, at most `TOL` is `Err(NoDirection)`; `b = a + x·r` with `x` the unit in-plane direction to the cursor, else `u`; goes to stage 2 (no cursor), nothing drawn. Stage 2: a bulge height via `parse_length`, error `Err(Parse(e))`; `h = |value|`, at most `TOL` is `Err(NoDirection)`. The side: the apex lies at `mid + side·h·left` where `mid = (a+b)/2`, `left = normal × (b - a)` normalised, and `side` is `-1` if the cursor is on the right of the chord (`(cursor_in_plane - mid)·left < 0`), else `+1` (no cursor: `+1`). Draw `three_point_arc(normal, a, b, apex, segments)`; `None` is `Err(NoDirection)`. The value's sign is ignored.
- `Cancel` from any stage goes idle.
