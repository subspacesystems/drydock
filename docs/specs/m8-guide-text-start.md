# m8-guide-text-start: guide pages, getting started and basic tools

The generator `drydock-guide` is merged. This task writes the first six real pages of the user guide as Markdown in `docs/guide/`. Only Markdown files are created; no Rust changes. Do not change the tests. A later task (`m8-guide-text-more`) adds more pages and extends `SUMMARY.md`, so keep your entries in the order below at the top of the list.

Write in plain, friendly English for someone new to 3D modeling, in your own words, second person ("click", "press"). Short paragraphs, bullet lists for steps, key names in backticks (`Shift`, `F2`). Use the product name Drydock; never "modeler", and name no other product. No images and no links outside the guide. Each `##` section named below needs at least 15 words; each page at least 250 words in total. Facts below come from the running app; state only what is here (do not invent features).

## `SUMMARY.md`

Format as the generator expects (`# User Guide`, then `- [Title](path.md)` lines, no nesting needed) listing, in order: `welcome.md`, `window.md`, `navigation.md`, `selecting.md`, `drawing.md`, `push-pull.md`.

## Pages and required headings

Each page starts with the `#` title shown; the `##` headings must appear exactly as written (more headings are fine). `welcome.md` links to each of the other five pages (link text of your choice, target written `window.md`, etc.).

- `welcome.md`: **Welcome to Drydock**. *What Drydock is*: a 3D modeler for designing parts to print; models are made of edges and faces; draw flat shapes then pull them into solids. *Where to start*: a short list linking the other pages in reading order.
- `window.md`: **The Drydock window**. *Menus*: File (New Ctrl+N, Open Ctrl+O, Import, Export, Save Ctrl+S, Save As Ctrl+Shift+S, Exit), Edit (undo, redo, cut/copy/paste, erase, make group or component, explode), View (projection, Zoom Extents, standard views, axes, panels, Reset Panels), Tools, Help (User Guide, key `F1`). *Toolbars and panels*: toolbars hold the tools; panels (Entity Info, Materials, Components, Shadows...) are opened from the View menu and can be put back with Reset Panels. *The measurements box*: shows the length, radius, segments or angle of what you are drawing; typing numbers goes there (see the drawing page).
- `navigation.md`: **Moving around**. *Orbit*: tool key `O`, or drag with the middle button. *Pan*: tool key `H`, or hold `Shift` while orbiting. *Zoom*: scroll wheel zooms toward the cursor; tool key `Z` zooms by dragging up and down; `Shift+Z` is Zoom Extents (fits the whole model). *Standard views*: `F2` Iso, `F3` Top, `F4` Front, `F5` Right, `F6` Back, `F7` Left, `F8` Bottom. *Perspective and parallel*: `Shift+P` switches between them (View menu too); parallel keeps parallel edges parallel, good for measuring by eye.
- `selecting.md`: **Selecting**. Select tool key `Space`. *Clicking*: click an edge or face to select it, click empty space to clear; a plain click replaces the selection. Double click selects the face or edge with everything bounding it; triple click selects everything connected to it. *Adding and removing*: `Shift` adds, `Ctrl` toggles (adds if not selected, removes if selected), `Alt` removes. *Selecting with a box*: drag left to right (window box): only things completely inside; drag right to left (crossing box): things inside or touching. The same modifier keys work with boxes. *Selecting connected geometry*: explains double and triple click with a small example (a box: double click a face selects it and its edges; triple click selects the whole box).
- `drawing.md`: **Drawing**. *Lines*: tool `L`; click a start, click the next point; each click continues the chain; `Esc` ends/cancels. The cursor snaps to endpoints, midpoints, centers, points on edges and faces, the ground, and along the red, green and blue axes; the hint beside the cursor names the snap (for example "Endpoint" or "On Red Axis"). *Rectangles*: tool `R`; click one corner, click the opposite corner. *Circles*: tool `C`; click the center, then the radius; typing a number followed by `s` (for example `12s`) before drawing sets the number of segments. *Arcs*: tool `A` draws an arc from center, start and sweep; `Shift+A` draws a three-point arc; segments can be typed the same way. *Typing values*: while drawing, type a number (with a unit such as `10cm` or `1/2"` if you like; without one the model's unit is used) and press `Enter`; a rectangle takes width and height separated by a comma; the measurements box shows what you typed. Backspace deletes the last character. *Locking a direction*: arrow keys lock the line to an axis (Right red, Left green, Up or Down blue; press again to release); holding `Shift` locks to the direction you are already showing.
- `push-pull.md`: **Push/Pull**. Tool key `P`. *Pushing a face*: click a face, move the cursor along the direction to pull it out or push it in (a preview shows the new shape), click again to finish. Snapping to a corner elsewhere in the model sets the height to match. A distance of zero does nothing; `Esc` abandons the push; undo takes back a finished one. *Typing a distance*: while pushing, type a length and press `Enter`; a negative number reverses the direction. Right after a push, typing a new length and `Enter` changes that push instead of adding another. *Repeating a push*: double click another face to push it by the same distance as the last push.
