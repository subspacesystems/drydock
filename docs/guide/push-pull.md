# Push/Pull

The toolbar button for this tool is called Extrude. Its key is `P`.

## Pushing a face

Click a face, then move the cursor in the direction you want the face to go. Pulling out makes the part longer, and pushing in makes it shorter. A preview shows the new shape while you move. Click again to finish. If the cursor snaps to a corner elsewhere in the model, the height is set to match that corner. A distance of zero does nothing. Press `Esc` to abandon the push, and use undo if you want to take back a finished one.

## Typing a distance

While pushing, type a length and press `Enter`. A negative number reverses the direction. Right after a push has finished, typing a new length and pressing `Enter` changes that push instead of adding another one. This is useful when you want to correct a measurement without starting over.

## Repeating a push

To repeat a push, double click another face and it moves by the same distance as the last push. The face follows the same direction rule as before, so you can repeat the same amount on several faces quickly.

## Before you start

Push/Pull needs a face to work on. If you have not made one yet, draw a rectangle first, as shown on the drawing page. Select the face you want to change with the tool, then move the cursor and watch the preview. Nothing is committed until you click a second time, so you can move back and forth and pick the direction that looks right. If the result is not what you wanted, undo it and try again.
