Keys are a quick way to pick a tool or a menu item. Press the key shown, without any other key unless the table says so.

## Modifier keys

Hold these keys while you use a tool; follow the link for the full story.

- [Select](selecting.md): `Shift` adds, `Ctrl` toggles, `Alt` removes.
- [Move](modify.md): `Ctrl` toggles copy.
- [Scale](modify.md): `Ctrl` scales about center, `Shift` uniform.
- [Tape Measure](measuring.md): `Ctrl` puts a guide point.
- [Paint Bucket](materials.md): `Alt` picks a material.
- [Drawing](drawing.md): arrow keys lock to an axis, `Shift` locks the current direction.
- [Orbit](navigation.md): `Shift` pans.
